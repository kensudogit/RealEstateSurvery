# 06. PowerPoint テンプレートへの差し込み（⑤）

実装は `scripts/pptx_fill.py`。テンプレートを用意して実行するだけで動く。

## テンプレートの作り方

営業が普段使っている pptx をそのまま流用する。約束ごとは 2 つだけ。

### 1. テキストは `{{key}}`

```text
{{property_name}}
所在地  {{address_display}}
交通    {{access_1}}
        {{access_2}}
価格    {{price}}
専有面積 {{exclusive_area_sqm}}
```

キーは `assets/property_fields.json` の `pptx` の値。
`{{meta.review_status}}` でメタ情報も差し込める。

### 2. 画像枠は図形の「名前」で指定する

画像を置きたい位置に四角形を置き、その図形の名前を `IMG:exterior` /
`IMG:floor_plan` / `IMG:map` / `IMG:interior` にする。図形の位置とサイズが
そのまま画像の枠になる。

名前の変更は PowerPoint の
**[ホーム] → [選択] → [オブジェクトの選択と表示]** から行う。
（テキストではなくオブジェクト名。ここを間違える人が多い）

枠に入れる画像が無い場合、既定では図形を残す。テンプレート側で
「写真準備中」の体裁を作り込んでいることが多く、消すとレイアウトが崩れるため。
素の四角形を出したくないときは `--drop-empty-frames` を付ける。

## run 分割の問題

python-pptx では 1 つの段落が複数の run に分割されていることが多い。
PowerPoint 上で一度でも入力を編集すると、`{{price}}` が
`{{pri` と `ce}}` のように割れる。素朴に `run.text.replace()` すると当たらない。

`_replace_in_text_frame()` は段落のテキストを結合してから置換し、
結果を先頭 run に書き戻して残りを空にする。書式は先頭 run のものに揃う。

同じ理由で、**表のセル・グループ図形の中・ノートページ**も走査する必要がある。
物件概要は表で組まれていることがほとんどなので、表を見落とすと何も差し込まれない。

## 単位はコード側で付ける

テンプレートに「万円」「㎡」を直接書かず、`format_value()` で付ける。
テンプレートを差し替えても表記が揺れない。

| 型・単位 | 出力例 |
|---|---|
| 円（1000万以上） | `4,800万円` |
| 円（1000万未満） | `8,500,000円` |
| 円/月 | `12,000円/月` |
| ㎡ | `62.50㎡（18.91坪）` |
| % | `7.20%` |
| YYYY-MM | `1993年3月` |
| null | `―` |

`―` を使うのは、空文字にすると「取得できなかった」のか
「もともと項目が無い」のか読み手に分からないため。

## 要確認の値の扱い

`needs_review` が立っている項目には `※要確認` を付けて出力する。
確認前の資料がそのまま客先に出るのを防ぐための保険。
確認が済んだ物件を出すときは `--no-review-marker` で外す。

運用としては、レビュー画面で全項目を確認済みにしてから最終版を再生成する
流れにする。要確認が残ったままの資料は、ファイル名に `_要確認` を付けて
最終版と区別できるようにしておくと事故が減る。

## 画像の前処理

`prepare_image()` が 2 つのことをやっている。

1. **EXIF Orientation の反映**（`ImageOps.exif_transpose`）。
   スマホ撮影の写真はそのまま貼ると横倒しになる。
2. **長辺を上限（既定 1600px）まで縮小**。元画像は 1 枚数 MB あることが多く、
   8 枚貼ると pptx がメール添付できない大きさになる。

配置は必ず contain（枠内にアスペクト比を保って収め、中央寄せ）。
間取り図を引き伸ばすと寸法が狂って見えるため、cover は使わない。

透過を持つ画像（間取り図の PNG など）は PNG のまま、写真は JPEG に変換して
サイズを落とす。

## テンプレート 2 種の運用

`mysoku`（1 枚もののマイソク）と `summary`（複数ページの物件概要書）で
必要な項目が違う。同じ `{{key}}` の語彙を共有し、テンプレートごとに
使う項目だけを書く。使わない項目があってもエラーにはならない。

逆に、テンプレートにあってデータに無いキーは `[警告] 未定義のプレースホルダ`
として報告し、終了コード 1 を返す。テンプレートの誤字を放置すると、
`{{proprety_name}}` がそのまま印刷された資料が客先に出る。

## PDF 化

営業が実際に配るのは PDF であることが多い。LibreOffice をコンテナに入れて
変換するのが手軽。

```bash
soffice --headless --convert-to pdf --outdir /data/documents result.pptx
```

日本語フォントを忘れずにインストールする（`fonts-noto-cjk`）。
これが無いと全部豆腐（□）になる。テンプレートで使っているフォントと
同じものを入れないと、レイアウトが崩れて改行位置が変わる。
